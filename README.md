Telegram Flooder Bot Бот для отправки запросов аутентификации в Telegram.

Установка Клонируйте репозиторий Установите зависимости: pip install -r requirements.txt Запустите: python bot.py Команды /start - информация /attack +79991234567 - начать атаку /stop - остановить /status - статус /stats - статистика
